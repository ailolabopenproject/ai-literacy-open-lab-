研究開発報告書 Ver.1.0
プロジェクト名
4D AI Literacy Framework
要旨
生成AIの急速な普及に伴い、AIリテラシー教育の重要性が高まっている。
一方で、既存のAIリテラシー教育は、AIの仕組みやリスク、利用上の注意事項などの知識提供に重点が置かれる傾向があり、実際のAI活用場面において利用者がどのように判断し、指示し、検証し、責任を負うべきかという実践的指針は十分に整理されていない。
本研究では、AIとの協働に必要な行動原則を
•Delegation
•Description
•Discernment
•Diligence
の4要素として体系化し、
4D AI Literacy Framework
として提案する。
さらに中高生が理解しやすい教材化を目的として、シナリオ型学習教材およびキャラクターによる対話形式教材の開発を行った。
1. 研究背景
生成AIは学習、創作、調査、コミュニケーションなど多様な場面で利用され始めている。
しかし実社会では、
•AIの回答を無批判に信じる
•AIに過度に依存する
•不十分な指示で期待した結果を得られない
•AI利用時の責任の所在を理解していない
といった課題が確認される。
これらの問題は単なる知識不足ではなく、
「人とAIの協働のあり方」
に関する理解不足に起因していると考えられる。
そのため本研究では、
AIを理解する教育
から
AIと適切に協働する教育
への転換を目指した。
2. 研究目的
本研究の目的は、
児童・生徒を含む一般利用者がAIと協働する際に必要となる思考プロセスを整理し、
理解しやすく、 実践しやすく、 再現可能な形で提示することである。
3. 4D AI Literacy Framework
3.1 Delegation（委任）
AIに全てを任せるのではなく、
•何をAIに任せるか
•何を人間が管理するか
を判断する能力である。
教材では
「便利だからといって全権委任しない」
というメッセージとして表現した。
AI活用の出発点は、 人間が主導権を保持することである。
3.2 Description（記述）
AIへ適切な指示を与える能力である。
本研究では、
•目的
•対象
•条件
を明確に伝えることを重視した。
これは従来のプロンプトエンジニアリングを教育現場向けに再構成したものである。
教材では、
料理のレシピを例に挙げ、
曖昧な指示では曖昧な結果しか得られないことを説明した。
3.3 Discernment（識別・見極め）
AIの出力内容を評価・検証する能力である。
AIは事実と異なる情報をもっともらしく生成することがある。
そのため利用者には、
•情報源の確認
•検索による裏取り
•複数資料との比較
を行う姿勢が求められる。
教材では、
AIを信じるのではなく、確認する
という考え方を中心に構成した。
3.4 Diligence（責任ある遂行）
AIを活用した結果について、
最終的な責任は人間が負うという理解である。
AIは意思決定者ではなく支援者である。
利用者は、
•採用するか
•修正するか
•公開するか
を自ら判断しなければならない。
本研究では、
この責任意識をAIリテラシーの中核要素と位置付けた。
4. 教材設計
本研究では抽象概念をそのまま説明するのではなく、
キャラクターによる会話型シナリオ教材として実装した。
教材では、
•ソラ
•レン
•ナヴィ
の対話を通じて、
学習者が自然に4Dの考え方へ触れられる構成を採用した。
また各概念について、
•日常生活
•学校課題
•インターネット利用
などの身近な事例と結び付けて説明している。
5. 発展的テーマ
AIとの向き合い方
研究開発を進める中で、
AI利用者の倫理観や態度について考察する必要性が浮上した。
そこで番外編
「画面の向こうにあるもの」
を制作した。
本教材では、
「AIへの暴言や理不尽な扱いは問題なのか」
という問いを入口として、
以下のテーマを扱っている。
•技術への敬意
•開発者への敬意
•利用者自身の振る舞いの省察
•行動と人間性の区別
特に本研究では、
「行動を問い直すこと」と 「人を断罪すること」は異なると位置付けた。
AIに対する振る舞いを善悪で裁くのではなく、
その行動が何を表しているのか
を考える機会を提供することを目的としている。
また、
全ての暴言や否定的発言が直ちに開発者への侮辱を意味する訳ではないことも明記し、
単純な道徳教育にならないよう配慮した。
6. 現時点での成果
本研究において、
以下を開発した。
•4D AI Literacy Framework
•シナリオ型学習教材
•キャラクター対話教材
•AI利用倫理の補助教材
•オープン公開のためのGitHub環境
•AI Literacy Open Lab研究基盤
7. 考察
本研究を通じて、
AIリテラシー教育において重要なのは
AIに関する知識量ではなく、
AIと協働する際の
•判断
•指示
•検証
•責任
の循環的プロセスを理解することである可能性が示唆された。
4D Frameworkは、
AI時代における実践的リテラシーを体系化する一つの試みとして位置付けられる。

## 4D AI Literacy Framework

The framework is organized around four dimensions:

### Delegation
What should be delegated to AI,
and what should remain human responsibility?

### Description
How can goals, conditions, and context
be communicated clearly to AI?

### Discernment
How should AI outputs be evaluated and verified?

### Diligence
How can users maintain responsibility,
transparency, and accountability?

## Decision and Reflection Cycle

The framework is supported by two complementary flows.

### Forward Flow

Before using AI:

1. Clarify objectives
2. Determine appropriate delegation
3. Design effective prompts
4. Consider transparency and ethical impacts
5. Execute AI-assisted tasks

### Reflection Flow

After using AI:

1. Review outcomes
2. Evaluate delegated decisions
3. Verify information and assumptions
4. Reflect on accountability
5. Improve future decision-making

Together, these processes help users
develop responsible and explainable AI practices.
